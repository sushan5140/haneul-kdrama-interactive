# Scene Visual Audit — Haneul K-Drama Interactive

Updated: 2026-09-16

Purpose: durable scene-by-scene visual continuity record. Every active scene must be checked against its assigned picture before an image is reused, swapped, or regenerated.

## Status legend
- ✅ Match — image fits the scene context.
- 🟡 Partial — usable, but one or more context details are off.
- 🔴 Mismatch — image conflicts with the scene.
- ♻️ Swap candidate — a different existing scene image may fit better.
- 🎨 Replacement — no suitable existing image; generate/replace.
- ⏳ Audit pending — not reviewed yet.

## Required checks for every scene
1. Story beat / what is happening.
2. Location / environment.
3. Characters present.
4. Character appearance continuity.
5. Physical action / pose / props.
6. Emotion / tone.
7. Time-of-day / lighting when story-relevant.
8. Current assigned image.
9. Match status.
10. Best reuse/swap candidate.
11. Replacement decision and notes.
